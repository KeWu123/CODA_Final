# Anatomy-Preserving Consistency Training

- Publication: Image and Vision Computing, 2026.
- Core idea: nonlinear grayscale transforms create weak/strong views without geometric anatomy distortion; attention-guided multi-scale feature consistency complements output consistency.
- Relevance: rules out "anatomy-preserving intensity perturbation" as a standalone novelty claim.
- Gap relative to ViSA-MT: uses a fixed perturbation family and consistency design; it does not select the hardest teacher-valid view per sample.
- Paper: https://www.sciencedirect.com/science/article/pii/S0262885625004214

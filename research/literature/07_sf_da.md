# SF-DA

- Paper: *Symmetry and Fusion Data Augmentation for Semi-Supervised Medical Segmentation*.
- Venue/year: ICASSP 2025.
- Core idea: self-symmetric flipping plus cross-sample stitching in Mean Teacher.
- Datasets: ACDC and PROMISE12.
- Relevance: direct collision with any flip+fusion proposal on the user's exact dataset.
- Code status: the paper points to a repository, but the repository currently states that implementation will not be made public.
- DOI: https://doi.org/10.1109/ICASSP49660.2025.10889068
- Repository: https://github.com/ZYS-four/SF-DA

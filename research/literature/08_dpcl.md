# Dual Perturbation Consistency Learning (DPCL)

- Publication: *Dual perturbation consistency learning for semi-supervised medical image segmentation*.
- Core idea: confidence-guided adaptive image perturbation based on image difficulty and model learning progress, plus mixed feature perturbation.
- Reported datasets include ACDC, PROMISE12, and LA.
- Relevance: directly rules out a paper whose only novelty is scheduling augmentation magnitude by learning progress.
- Gap relative to ViSA-MT: ViSA-MT separates teacher-estimated semantic validity from student utility and makes a constrained choice among candidate views.
- Source summary: https://www.canyam.com/en/article/dual-perturbation-consistency-learning-for-semi-supervised-medical-image-segmentation/62562236
